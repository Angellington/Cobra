## Versão do Python utilizada
> Python 3.13.13
## Como criar e ativar ambiente
1. No root utilize `python3 -m venv .venv` e assim será criado a venv
2. Para ativar, utilize do comando `source .venv\bin\activate`
3. PowerShell `/Scripts/Activate.ps1`
4. CMC `/Scripts/activate.bat`
5. Para instalar as dependências faça: `python -m pip install -r requirements.txt`
